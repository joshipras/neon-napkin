# NYK After Dark

A mobile-first, installable Knicks Finals hype companion built with Next.js,
Tailwind CSS, and Lucide React.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The scoreboard is intentionally simulated and clearly labeled as such. The PWA
service worker is registered in production builds.
